# Intelligent Energy-Aware Campus Resource Scheduling System

## Prerequisites

- SWI-Prolog: [Download](https://www.swi-prolog.org/download/stable/bin/swipl-10.0.2-1.x64.exe.envelope)
- VS Code extension: VSC-Prolog

## How to Run

```bash
swipl main.pl
```
